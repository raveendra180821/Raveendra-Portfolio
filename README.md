# THOR — Portfolio

Personal portfolio for **THOR**, Full Stack Developer / Product Integration Engineer I.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Replace placeholders

Update `src/data/content.js`:

- `YOUR_EMAIL`
- `YOUR_GITHUB_URL`
- `YOUR_LINKEDIN_URL`

Add your resume PDF at `public/resume.pdf`.

Add more projects by appending objects to `PROJECTS` in `src/data/content.js`.
